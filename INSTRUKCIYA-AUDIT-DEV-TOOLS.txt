А. Деплой на v2.2 (преди смяната на домейна — може веднага):
   1. Копирай ЦЕЛИЯ съдържание на папката dev-tools/ в локалното
      ти копие на fedya-dev/dev-tools (с презапис). Не копирай
      .git (няма такава папка в пакета — ползвай своята).
   2. В терминала:
        git add -A
        git commit -m "Dev Tools Pro v2.2 — миграция към dev.serafiev.com, единен бранд, SEO одит"
        git push
   3. Cloudflare Pages ще build-не автоматично. Нищо друго не трябва.

Б. Смяна на поддомейна (когато си готов):
   1. Cloudflare Dashboard → Workers & Pages → твоя Pages проект
      (dev tools) → Custom domains → Set up a custom domain.
   2. Въведи: dev.serafiev.com → ако зоната serafiev.com е в същия
      акаунт, CF ще добави CNAME автоматично към
      <project>.pages.dev и ще активира SSL. Кликни Activate.
   3. Провери https://dev.serafiev.com/ (иконата ">_" в таба е
      знак, че новият бранд е жив).
   4. Старият dev.fedia.eu custom domain: остави го ОЩЕ 1–2 седм.
      (линковете ще работят), после го махни от Pages проекта.
      Ако искаш, направи 301 от fedia.eu зоната → dev.serafiev.com
      (Bulk Redirects или Redirect Rule в CF).
   5. Google Search Console → Add property → dev.serafiev.com →
      подай sitemap.xml (URL-ите в него вече са новите).
   6. llms.txt и sitemap.xml вече сочат новия домейн — нищо
      допълнително не се пипа.

В. Две неща за реши ТИ (не съм ги пипнал нарочно):
   1. config.json — паролата е "СМЕНИ-СИ-ПАРОЛАТА-ТУК" и файлът е
