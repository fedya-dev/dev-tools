💡 Как работи:
  • Въведи стария URL-encoded адрес в първото поле
  • Въведи новия URL адрес във второто поле
  • Натисни „Добави към списъка“ за да запазиш директивата
  • Повтори за всички URL-и, които искаш да препратиш
  • Копирай всички наведнъж за .htaccess файла

▶ Как да инсталираш yt-dlp и ffmpeg
Разгъни инструкциите

Windows:
winget install yt-dlp
winget install ffmpeg

macOS:
brew install yt-dlp ffmpeg

Linux:
sudo apt install yt-dlp ffmpeg  или  pip install -U yt-dlp

След това копирай генерираната команда и я пусни в терминал.
